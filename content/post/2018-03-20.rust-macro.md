1.宏需要声明在前

不能在宏定义之前调用宏。因为rust会在遇到宏调用的时候直接展开，展开时不会去看宏调用后面的代码

You can’t call a macro before it is defined, because Rust expands each macro call before it even looks at the rest of the program

函数调用则不用关心定义的顺序
