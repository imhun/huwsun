Compiler intrinsics

<!-- more -->

Intrinsics 为编译器内部功能，需要通过rust-intrinsics ABI来调用，调用时需要当成FFI函数来导入，因此总是unsafe的。

比如

```rust
extern "rust-intrinsic" {
fn transmute<T, U>(x: T) -> U;
fn offset<T>(dst: *const T, offset: isize) -> *const T;
}
core::intrinsics模块就是intrinsics的FFI导入
```
