标准库unsafe

<!-- more -->

- slice::get_unchecked

- mem::transmute reinterprets some value as having a given type, bypassing type safety in arbitrary ways

- Every raw pointer to a sized type has an offset method that invokes Undefined Behavior if the passed offset is not ["in bounds"](file:///Users/polus/.rustup/toolchains/nightly-x86_64-apple-darwin/share/doc/rust/html/std/primitive.pointer.html#method.offset).

- All FFI (Foreign Function Interface) functions are unsafe to call because the other language can do arbitrary operations that the Rust compiler can't check.

- Send is a marker trait (a trait with no API) that promises implementors are safe to send (move) to another thread.

- Sync is a marker trait that promises threads can safely share implementors through a shared reference.

标准库许多代码内存使用了unsafe，这些实现经过了严格的手工检查，因此在此基础上构建的接口可以认为是安全的。

会导致未定义行为的操作

- Dereferencing null, dangling, or unaligned pointers

- Reading [uninitialized memory](file:///Users/polus/.rustup/toolchains/nightly-x86_64-apple-darwin/share/doc/rust/html/nomicon/uninitialized.html)

- Breaking the [pointer aliasing rules](file:///Users/polus/.rustup/toolchains/nightly-x86_64-apple-darwin/share/doc/rust/html/nomicon/references.html)

Producing invalid primitive values:

- dangling/null references

- a bool that isn't 0 or 1

- an undefined enum discriminant

- a char outside the ranges [0x0, 0xD7FF] and [0xE000, 0x10FFFF]

- A non-utf8 str

- Unwinding into another language

- Causing a [data race](file:///Users/polus/.rustup/toolchains/nightly-x86_64-apple-darwin/share/doc/rust/html/nomicon/races.html)

```rust
unsafe操作的正确性不仅取决于unsafe代码本身，还依赖由safe代码确定的状态
```
