```rust
format_string := <text> [ format <text> ] *
format := '{' [ argument ] [ ':' format_spec ] '}'
argument := integer | identifier
format_spec := [[fill]align][sign]['#'][0][width]['.' precision][type]
fill := character
align := '<' | '^' | '>'
sign := '+' | '-'
width := count
precision := count | '*'
type := identifier | ''
count := parameter | integer
parameter := integer '$'
```

运算符

```rust
==对应trait  PartialEq
```

严格的相等关系满足如下条件

1.如果x==y，则y==x

2.如果x==y 且 y==z，则x==z

3.x==x

```rust
但是在浮点数中0.0/0.0的结果为非数字，表示为NaN，NaN不等于任何其他值，包括自身，因此浮点数的满足相等关系的前两个条件，但不满足第三个条件，所以用PartialEq来作为相等的trait
```

严格的相等关系使用trait Eq，除了f32和f64，标准库的其他类型同时实现了PartialEq和Eq

```rust
trait Eq: PartialEq<Self> { }
比较运算，>,<,>=,<=，对应trait PartialOrd
trait PartialOrd<Rhs = Self>: PartialEq<Rhs> where Rhs: ?Sized
{
fn partial_cmp(&self, other: &Rhs) -> Option<Ordering>;
fn lt(&self, other: &Rhs) -> bool { ... }
fn le(&self, other: &Rhs) -> bool { ... }
fn gt(&self, other: &Rhs) -> bool { ... }
fn ge(&self, other: &Rhs) -> bool { ... }
}
PartialOrd必须实现的方法为partial_cmp，返回的enum类型
enum Ordering {
Less, // self < other
Equal, // self == other
Greater, // self > other
}
Partial_cmp 如果返回None，则表示比较的操作数不存在顺序关系，原生类型中，只有浮点数中NaN与其他值比较的时候返回None
```
