> 前置：[An alias-based formulation of the borrow checker](https://smallcultfollowing.com/babysteps/blog/2018/04/27/an-alias-based-formulation-of-the-borrow-checker/)

Polonius 的核心表述是：`'a` 不是“生命周期”（代码区间的集合），而是“**一组借出（loan）**”。`'a: 'b` 是**子集**关系。借出活跃时它的条款必须被遵守——共享借用意味着被借的路径不能被修改，可变借用意味着那条路径完全不能被访问。

<!-- more -->

这个表述描述了核心的借用检查，但**不完整**：它不处理移动与初始化，也不检查具名生命周期之间的关系。这篇补的是后者，具体是“由子集关系引发的错误”这一类。

## 一类新的错误：没有访问，只有子集关系

```rust
fn foo<'a, 'b>(x: &'a [u32], y: &'b [u32]) -> &'a u32 {
    &y[0]
}
```

声明返回 `'a` 的数据，实际返回的是 `'b` 的数据。MIR 只有一条有意义的语句：

```text
fn foo(_1: &'a [u32], _2: &'b [u32]) -> &'a [u32] {
  _0 = &'X (*_2)[const 0usize]; // S0
  return;
}
```

由此产生两条事实：再借用 `*_2` 让 `'b` 和借用的 region `'X` 建立子集关系；把 `&'X u32` 赋给类型为 `&'a [u32]` 的 `_0` 要求 `'X: 'a`。合起来推出 `subset('b, 'a)`。

但 `'a` 和 `'b` 是函数的参数，`foo` 必须对**任意**取值成立，所以不可能知道它们之间有没有子集关系——报错。

关键在于这是**另一类**错误：整个函数里没有任何非法访问，只有子集关系。

## placeholder region

要处理这类错误，得区分两种 region。`'a`、`'b` 必须对**所有**取值成立，叫全称量化；为某次借用创建的 `'X` 只需**存在**一个有效取值，叫存在量化。

这篇把前者叫 **placeholder region**：它并不代表一个已知的借出集合，只是某个未知集合的占位符。它们需要一条标记事实（实际实现里叫 `universal_region`，作者打算改名）：

```text
placeholder_region('a).
placeholder_region('b).
```

placeholder region 在控制流图的所有点上都是“活跃”的——我们总是假设将来可能有看不见的用法。

## 已知关系

不过 placeholder region 并非完全未知：where 子句和 implied bounds 能给出已知关系。`where 'b: 'a` 产生 `known_base_subset('b, 'a)`；`&'a &'b u32` 这种带嵌套 region 的参数也会按 implied bounds 规则产生类似事实。

这些已知关系是传递的：

```text
known_subset(R1, R2) :- known_base_subset(R1, R2).
known_subset(R1, R3) :- known_base_subset(R1, R2), known_subset(R2, R3).
```

## 报错规则

思路很简单：要求两个 placeholder region 之间有子集关系，而它又不是“已知子集”，就报错。

```text
subset_error(R1, R2, P) :-
  subset(R1, R2, P),      // 在 P 处要求 `R1: R2`
  placeholder_region(R1),
  placeholder_region(R2),
  !known_subset(R1, R2).  // 不是已知子集
```

用到否定推理没问题，只要程序是**分层的**——`known_subset` 只依赖输入关系，不依赖 `subset_error`，所以这里显然分层。

## 一个机制不同的例子

```rust
fn bar<'a>(x: &'a [u32]) -> &'a u32 {
    let stack_slot = x[0];
    &stack_slot
}
```

这个也报错，但原因不是上面那套：为 `&stack_slot` 创建的借出成了 `'a` 的成员，于是在 `stack_slot` 的存储从栈上弹出时它仍然是活跃的——存储槽还有指向它的活跃借出时不能弹出。

## 附录：更高效的写法

上面的规则依赖传递的 `subset` 关系，而优化过的实现不计算完整的传递闭包。所以可以专门建一个针对 placeholder 的关系，只算到 placeholder 相关的部分：

```text
subset_placeholder(R1, R2, P) :- subset(R1, R2, P), placeholder_region(R1).
subset_placeholder(R1, R3, P) :- subset_placeholder(R1, R2, P), subset(R2, R3, P).
```
